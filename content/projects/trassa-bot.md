**Готовая к коммерческому запуску автономная Telegram-платформа** для секторов логистики, магистральных перевозок и придорожного ритейла.

**Архитектурный стек:** Python (aiogram 3.x) + Pydantic-settings (`.env` конфигурация) + поддержка СУБД (SQLite для быстрого старта / PostgreSQL для продакшена) + Redis (кэш сессий).

## 📦 Главные коммерческие триггеры платформы

**🧠 Гибридный ИИ-модуль (Ollama / OpenAI)**

В ядро интегрирован гибкий AI-провайдер. Стартап работает через облачный API OpenAI **или** абсолютно бесплатно и автономно — на вашем сервере через локальную нейросеть Ollama (модели уровня Llama/Mistral). ИИ готов к обработке входящих текстовых и голосовых запросов от водителей **без затрат на зарубежные подписки**.

**💳 Встроенный легальный эквайринг (ЮKassa)**

Бизнес-логика полностью готова к приёму платежей на территории РФ. Интеграция с ЮKassa (`SHOP_ID`, `SECRET_KEY`) зашита на уровне ядра конфигурации. Приём оплаты за Premium-подписки водителей или рекламные места придорожного бизнеса работает **из коробки** — достаточно вписать свои ключи в `.env`.

**⏱ Модуль РТО (Режим труда и отдыха)**

Асинхронный цифровой тахограф-трекер для водителей. Включает алгоритм автоматического восстановления активных рабочих смен из базы данных при перезапуске сервера — непрерывность логистического контроля гарантирована.

**🛣 Снабжение, логистика и инфраструктура**

Каталог и архитектура под оцифровку придорожных коммерческих точек (АЗС, мотели, СТО). Готовая **B2B-модель** для монетизации трафика и взаимодействия водителей со складскими и сервисными базами.

**🛡 Архитектурная безопасность**

Встроенные слои `AntiFloodMiddleware` (защита от спама и DDoS) и `CheckPremiumMiddleware` (автоматический контроль уровней доступа и тарифных планов пользователей).

## 🔧 Техническая автономность продукта

Проект спроектирован по принципу **максимальной отчуждаемости**. Благодаря `pydantic-settings` управление всей платформой происходит в одном файле `.env` без изменения исходного кода:

- Переключение между ИИ-провайдерами
- Смена токенов
- Подключение платёжек
- Перевод базы с SQLite на PostgreSQL
- Переключение на режим Webhook
